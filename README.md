# Data-Centric AI: Enhancing Model Performance through Data Quality Optimization

This repository contains the codebase, datasets, and analysis for the research project titled **"Data-Centric AI: Enhancing Model Performance through Data Quality Optimization"**. This project explores how enhancing the quality of training data can lead to substantial improvements in machine learning model performance—without altering the model architecture.

---

## 📌 Abstract

In contrast to traditional model-centric approaches, this project adopts a **data-centric AI** perspective—focusing on improving the **quality, consistency, and balance of data** to optimize model accuracy, generalization, and robustness. We demonstrate that high-quality datasets can outperform complex models trained on noisy or imbalanced data.

---

## ⚙️ Features

- 🧹 **Data Cleaning & Label Correction**
- 🔄 **Data Augmentation & Balancing (SMOTE, Oversampling)**
- 📊 **Data Quality Visualization (via Seaborn & Matplotlib)**
- 🤖 **Model Training & Performance Evaluation**
- 📈 **Comparative Results: Noisy vs Clean Data**
